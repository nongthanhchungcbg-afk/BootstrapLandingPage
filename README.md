# Bootstrap Landing Page

A responsive Bootstrap landing page with a collapsible navbar, hero, services grid, service cards, customer story, CTA, and footer.

## Run

Open `index.html` with an internet connection so Bootstrap 5.3 and Google Fonts can load.
